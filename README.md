# Pepper Heat Prediction

## Overview
This project predicts the Scoville Heat Units (SHU) of peppers using machine learning techniques and agricultural measurement data.

## Technologies
- Python
- NumPy
- Pandas
- Scikit-Learn

## Features
- Data cleaning
- One-hot encoding
- Missing value handling
- Outlier removal using Z-score
- Feature selection
- Random Forest modeling
- SHU prediction

## Machine Learning Workflow
1. Data Preprocessing
2. Feature Engineering
3. Outlier Detection
4. Model Training
5. Prediction Generation

## Goal
Predict pepper heat levels based on physical and chemical properties.
